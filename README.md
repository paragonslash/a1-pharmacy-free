# A1 Pharmacy — Free Edition

A five-page cut of a twenty-two page pharmacy and e-commerce template. Plain
HTML, hand-written CSS and vanilla JavaScript. No framework, no build step, no
`npm install`.

**[Live demo →](https://paragonslash.github.io/a1-pharmacy-free/)**

Clone it, or download the ZIP, open `index.html`, and it works straight off
the disk. There is nothing to run first.

```sh
git clone https://github.com/paragonslash/a1-pharmacy-free.git
cd a1-pharmacy-free
open index.html          # or just double-click it
```

## What's here

| | |
| --- | --- |
| `index.html` | home |
| `shop.html` | catalogue, with working filters |
| `product.html` | product detail |
| `contact.html` | contact and opening hours |
| `404.html` | not found |

Plus the complete stylesheet and script layers from the full edition — so the
components on these five pages are not the only ones present, only the ones
with a page to sit on. Everything is driven from `css/tokens.css`: colours,
the two typefaces, the type scale. Rebrand from that one file.

- No build step, no dependencies, no JavaScript framework.
- Responsive and keyboard-navigable.
- Self-hosted fonts (Archivo and IBM Plex Mono, both OFL).

## What the full edition adds

Seventeen more pages: repeat prescriptions, clinical services, a journal with
six articles, about, bag, checkout, account, three legal pages, and a component
reference showing every button, field, card, table, accordion, toast, overlay
and tab with the markup each one needs. Plus full documentation and an optional
production bundler.

**There is no bag, checkout or account in this repo.** You can build a
catalogue with the free edition; you cannot build a shop.

## Before you publish

Every piece of content is fictional and there for layout. Registration,
premises and company numbers are deliberately zeroed — publishing them
unchanged would be a false claim of registration with a real regulator. Product
copy and dosing text are sample copy, not medical advice. Pharmacy and
healthcare sites are regulated almost everywhere; meeting the rules that apply
to you is your responsibility, not the template's.

The images are generated placeholders, not photography. Replace them.
